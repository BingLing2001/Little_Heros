# 小小英雄 · 安装包与更新

这是小小英雄的公开安装包发布仓库，不包含游戏开发源码、私钥或玩家数据。

## 下载与安装

经版本验收的 Windows 安装包发布后，请在 [Releases](https://github.com/BingLing2001/Little_Heros/releases) 中下载 `little-heroes-版本号-x64-setup.exe`。

若 Releases 暂无正式版本，表示尚未发布可下载的安装包。请勿把 GitHub 自动生成的 “Source code (zip)” 当作游戏安装包。

## 在线更新

带在线更新功能的版本支持在登录页或游戏设置中检查更新。点击“安装最新版”后下载、校验并安装，保留原有玩家数据。没有更新功能的早期版本需先手动安装一次支持在线更新的版本。

下载优先使用本仓库附件；网络失败时使用官方备用源。下载可取消。安装前保存游戏数据并退出游戏，Windows 可能要求用户确认。

签名和 SHA-256 用于检查发布文件是否完整，不能替代 Windows 代码签名或系统安全提示。当前不提供 macOS 安装包。

## 发布附件

- `little-heroes-版本号-x64-setup.exe`：玩家安装包。
- 同名 `.sig`：安装包的更新签名，无需玩家手动打开。
- `release.json`、`release.json.sig`：带签名的版本、主备下载地址及文件摘要。
- `release-notes.md`：该版本更新说明。

发布者只上传上述附件；不要上传整个工程、`.private`、签名私钥、账号授权或玩家存档。
